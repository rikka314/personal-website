## Deployment correction

The old deployment scripts pointed to:

```text
/var/www/personal-website
```

But the live nginx configuration for `gfm156.com` actually serves:

```text
/www/wwwroot/www.gfm156.com
```

The deployment scripts in this repository were updated to use the real live path and the real nginx reload command:

```text
/www/server/nginx/sbin/nginx -t
/www/server/nginx/sbin/nginx -s reload
```
